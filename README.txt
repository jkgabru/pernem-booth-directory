PERNEM BOOTH DIRECTORY — DEMO
1. Extract the ZIP.
2. For best offline/PWA behaviour, serve this folder from a local or hosted HTTPS static web server.
3. Open index.html for a basic preview. Service-worker offline caching requires localhost or HTTPS.
Included: 51 booth/locality index, search, area filter, responsive layout, offline app-shell cache.
Not included: individual voter data, PDF hosting, real authentication, admin accounts, server sync, or secure multi-user editing.
The locality labels are based on the booth/locality mapping supplied in the project conversation and should be checked against the latest official roll before publication.
